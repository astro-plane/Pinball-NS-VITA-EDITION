# Pinball NS — Vita Edition

**Pokémon Pinball on the PS Vita, with the whole table on one screen.**

This is the PS Vita / PS TV port of [Pinball NS](https://github.com/ReiniShari/Pinball-NS) by Reinhard Sharapov. In the original Game Boy Color game, each table is split into a top half and a bottom half, and the screen goes blank while the other half loads. Pinball NS joins them into a single field: both halves run together, and the ball rolls from one to the other with no loading. The original physics are kept, so it plays like the cartridge.

The Vita Edition adds a native ARM front-end. The Game Boy's CPU is emulated in ARM assembly written for the Vita's Cortex-A9, so the game runs at full speed.

It also plays **Pokémon Pinball Generations 1.6** by RainbowDevs, with its Gold and Silver tables.

## Features

- **Two ways to hold it**
  - **Landscape:** the table fills the screen. L / R are the flippers and CROSS launches.
  - **Portrait:** hold the Vita sideways for the phone-style screen, with the table on top and big touch flippers below.
- **Choose at the start:** which game (when you have both) and which orientation, or turn ASK AT START off to go straight in.
- **One button for everything:** SELECT opens the menu in either orientation. From there you can switch orientation, save or load, change the sound, motion tilt and colours, or swap games.
- **Shake to tilt:** shake the Vita up and down for the upper tilt, or tap its left or right side to nudge the table that way.
- **Rumble on PS TV** with a DualShock 3 or 4, for the Rumble version of the cartridge.
- **Sharp pixels** at any size, scaled on the GPU.
- **Native speed:** the CPU core is in ARM assembly, the picture uses NEON, and the sound runs on its own thread.

## Installing

1. You need a PS Vita or PS TV with homebrew enabled (HENkaku / Ensō) and VitaShell.
2. Download `PinballNS.vpk` from [Releases](../../releases) and install it with VitaShell.
3. Copy your ROM to `ux0:data/PinballNS/`:
   - **Pokémon Pinball**, the US version (*Pokémon Pinball (USA, Australia) (Rumble Version)*), dumped from your own cartridge, as a `.gbc` file.
   - Optionally, **Pokémon Pinball Generations 1.6**: the [RainbowDevs](https://rainbowdevs.com/title/pinball/) patch applied to that ROM.

Saves, saved states and settings are kept in the same folder. No ROMs are included or linked here.

## Controls

| | Landscape | Portrait |
|---|---|---|
| Flippers | L / R (or tap the left / right half of the screen) | the touch flippers, or L / R |
| Launch / confirm | CROSS | the touch keys, or CROSS |
| Tilt | d-pad down / CIRCLE / TRIANGLE, or shake the Vita | the T pad, or shake the Vita |
| Game menus | d-pad, START | d-pad, START |
| Pinball NS menu | SELECT | SELECT (or the MENU key) |
| Switch orientation | SELECT + L + R, or ORIENTATION in the menu | same |

In the landscape menu, the d-pad moves, CROSS or START picks, and CIRCLE goes back. You can also tap an entry.

**Generations:** on the game's FIELD SELECT screen, press **down** to reach the new tables.

## Building

You need [VitaSDK](https://vitasdk.org) with vita2d.

```
cmake -S platform/vita -B build/vita -G Ninja
cmake --build build/vita        # build/vita/PinballNS.vpk
```

The Vita code is in [`platform/vita/`](platform/vita), and its README has the details. The ARM32 CPU core is generated by `tools/gencpu.c` (backend `tools/gencpu_a32.inc`) into `src/core/cpu_a32.S`, and it was checked instruction by instruction against the C interpreter (`tools/cpucheck.c`). The rest of the project, including the Android, iPhone, Windows, macOS and Linux versions, is unchanged from upstream. See [the original README](https://github.com/ReiniShari/Pinball-NS#readme).
