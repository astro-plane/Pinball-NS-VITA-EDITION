# Pinball NS for PS Vita

Build (VitaSDK with vita2d):

```
cmake -S platform/vita -B build/vita -G Ninja && cmake --build build/vita
```

Install `build/vita/PinballNS.vpk`, then copy the ROM of your own cartridge (Pokémon Pinball, US version, `.gbc`;
or Pokémon Pinball Generations 1.6) to `ux0:data/PinballNS/`. Saves, states and settings are kept there too.

## At the start

With both ROMs in the folder, a first screen asks which game (Pokémon Pinball or Generations); then one asks how
the Vita is held (the last choices highlighted). The d-pad moves, CROSS or START takes it, or tap it; SELECT + L + R
also switches the orientation. Set ASK AT START (the last row) to NO and neither screen is shown again: the game
starts as last chosen. GAME, ORIENTATION and ASK AT START are in the menu too.

## Two ways to hold it

**Landscape**: the table alone. L / R the flippers (or the touch screen's left / right half), CROSS launches and
confirms, the d-pad and START for the game's menus, d-pad down / CIRCLE / TRIANGLE tilt left / right / up.

**Portrait** (d-pad down): the screen of the phone versions: the table on top, its touch keys under it (both
flippers, T for the tilts, MENU and START), the menu. The buttons work too.

The rear touch pad is not used.

## Rumble

On a PS TV with a DualShock 3 or 4, the controller rumbles with the game (the Rumble version of the cartridge);
VIBRATION in the menu turns it off. A Vita has no motor.

## Shake to tilt

Shake the Vita up and down for the upper tilt; tap its left or right side to tilt the table that way (as the
phone versions). Only on the table and the bonus stages. MOTION TILT in the menu turns it off and on.

## The menu

SELECT opens it (and closes it), landscape or portrait: resume, quick save / load, ORIENTATION (landscape /
portrait), vibration, sound, motion tilt, colours, the other game, restart, quit; in portrait
also the touch keys and ABOUT. In landscape the d-pad chooses, CROSS or START does, CIRCLE goes back (or tap).
SELECT + L + R also switches the orientation; there are no other SELECT combinations.

## Generations

On the game's FIELD SELECT screen, press DOWN for the tables of Generations (Gold, Silver...).

## Speed

The Game Boy's CPU runs in ARM assembly written for the Vita (src/core/cpu_a32.S, generated by tools/gencpu.c with
the 32-bit ARM backend in tools/gencpu_a32.inc), checked instruction by instruction against the reference interpreter
(tools/cpucheck.c); the picture uses the Cortex-A9's NEON unit.

Pixels are drawn sharp at any size (each pixel enlarged whole, then fitted: "sharp bilinear").
